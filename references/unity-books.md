# Unity book sources

The source PDFs were supplied in `Books`. The PDF page numbers in the workflows are one-based viewer positions, including covers. The workflows and checks are original paraphrases and applications. The PDFs remain in the supplied folder.

Several books cover older Unity or package releases. For implementation, inspect the project version and read the matching Unity and package documentation before using a version-sensitive API, menu path, or rendering feature.

### U1

`create-modular-game-architecture-in-unity-with-scriptableobjects.pdf` — Unity. ScriptableObject data and event channels. See PDF pp. 4–10 and 48–55.

### U2

`introduction-to-the-universal-render-pipeline-for-advanced-unity-creators-2021-lts-edition.pdf` — Unity. Render Objects and pipeline settings. See PDF pp. 76–78 and 120–123.

### U3

`level-up-your-code-with-game-programming-patterns.pdf` — Unity. Object pool pattern. See PDF pp. 45–51.

### U4

`optimize-your-console-and-pc-game-performance.pdf` — Unity. Asset and rendering diagnostics. See PDF pp. 32–38 and 54–58.

### U5

`The Unity Shaders Bible (Jettelly).pdf` — Jettelly. Keyword-driven shader variants. See PDF pp. 52–53.

### U6

`the-definitive-guide-to-creating-advanced-visual-effects-in-unity.pdf` — Unity. VFX subgraphs and rendering diagnostics. See PDF pp. 27–28 and 99–102.

### U7

`Unity Mobile Optimizing.pdf` — Community notes on older mobile hardware and settings. See PDF pp. 1–2. Use settings as experiments for the target project and hardware.

### U8

`unity-e-book-optimize-your-mobile-game-performance.pdf` — Unity. Platform texture import and mobile rendering costs. See PDF pp. 25–26 and 29–39.

### U9

`unity-game-dev-field-guide.pdf` — Unity. Prefabs and profiling tools. See PDF pp. 34–36 and 58–59.

### U10

`user-interface-design-and-implementation-in-unity.pdf` — Unity. UI implementation, including UI Toolkit authoring and flex layout. See PDF pp. 72–82.

### U11

`Visualizing Equations Essential Math for Game Devs.pdf` — Dot-product visualization and quaternions. See PDF pp. 8–22, 29–35, and Chapter 3.
