# Game Development Techniques

An agent skill with 350 references for designing, implementing, and verifying game features. The guides use shipped-game examples and developer sources to explain the problems each technique solves and how to check it in your project.

## Use the skill

Copy this repository folder into your agent's user or project skills directory as `game-development-techniques`. In Codex, use `~/.agents/skills/` for user-wide discovery or `.agents/skills/` inside your project. Keep [SKILL.md](SKILL.md) and the [references](references/) directory together.

> Use $game-development-techniques to diagnose why my third-person camera clips through doorways. Open the relevant guide and propose a repeatable in-game check.

Agents without a skill picker can open [SKILL.md](SKILL.md) directly.
